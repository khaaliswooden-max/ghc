\section{Implementation}
\label{sec:impl}

The GHC reference implementation is co-designed with this paper. Code
artifacts referenced below are reproducible from the GHC repository.

\paragraph{Proofs.}
\path{proofs/} contains the kernel Lean~4 \cite{lean4} formalization
in pure Lean 4 (no \texttt{mathlib} dependency); 20-second builds.
\path{proofs-mathlib/} contains the Phase B+ extensions on top of
mathlib4 \cite{mathlib4} (density-matrix purity, charpoly under
relabel, Chebyshev/Chernoff audit concentration, exponential channel
survival). Both trees are gated by CI to contain zero \texttt{sorry}s
and zero unsafe \texttt{axiom}s.

\paragraph{Core (Rust).}
The \path{core/} workspace ships four crates that are runtime mirrors
of the proven theorems, with property tests (\texttt{proptest}) that
re-establish each Lean invariant in Rust so that any drift between
formalization and runtime breaks the build:

\begin{itemize}
\item \texttt{ghc-algebra}: \texttt{Verdict} lattice (mirroring
  \texttt{Ghc.Verdict}), \texttt{Process} + \texttt{halal\_closure}
  (\texttt{Ghc.Process}), \texttt{Batch} + \texttt{Contribution}
  (\texttt{Ghc.Quantum.Batch}), deterministic and stochastic channels
  (\texttt{Ghc.Info} and \texttt{GhcMathlib.Channel}), and audit
  \texttt{plurality} (\texttt{Ghc.Convergence}). 29 unit and property
  tests.
\item \texttt{ghc-graph}: \texttt{ProvenanceDag} with
  \texttt{weight\_seq} / \texttt{count\_weight} / \texttt{total\_weight}
  (mirroring \texttt{Spectral.Graph}); \texttt{fingerprint} computes
  the top-$k$ eigenvalues of the normalized weighted Laplacian via
  \texttt{nalgebra::SymmetricEigen}. 5 tests including bijective
  spectral invariance.
\item \texttt{ghc-zk}: zk-Halal Groth16 over BLS12-381 via arkworks
  \cite{arkworks}. The \texttt{HalalThresholdCircuit} encodes
  (i)~domain check $w_i (w_i - 1)(w_i - 2) = 0$ forcing
  $w_i \in \{\halal, \mashbuh, \haram\}$, (ii)~threshold check
  ($w_i = 0$ for \halal-only, $w_i (w_i - 1) = 0$ for $\leq \mashbuh$),
  and (iii)~a Poseidon binding commitment
  $c = \mathsf{Poseidon}(\mathrm{salt} \,\Vert\, w_0 \,\Vert\, \dotsb
  \,\Vert\, w_{n-1})$ on BLS12-381 (width 3, $\alpha = 17$, 8 full +
  29 partial rounds), via \texttt{ark-crypto-primitives}. 8 tests
  including hostile-witness rejection and a
  \texttt{native\_and\_circuit\_poseidon\_agree} equality check that
  guarantees the off-circuit commit() and the in-circuit
  \texttt{PoseidonSpongeVar} produce byte-identical outputs.
\item \texttt{ghc-cli}: the \texttt{ghc} binary surfaces
  \texttt{closure}, \texttt{plurality}, \texttt{fingerprint},
  \texttt{prove}, \texttt{verify}, and an end-to-end \texttt{demo}.
\end{itemize}

\paragraph{Reference benchmarks.} On a stock x86\_64 Linux runner,
the v0.0.x \texttt{HalalThresholdCircuit} with $n = 3$ and
Poseidon-on-BLS12-381 commitment produces a 192-byte Groth16 proof
(release build):

\begin{center}
\begin{tabular}{lr}
\toprule
Operation & Wall time \\
\midrule
\texttt{Groth16::circuit\_specific\_setup} & 57 ms \\
\texttt{Groth16::prove}                    & 54 ms \\
\texttt{Groth16::verify}                   & 2.3 ms \\
\bottomrule
\end{tabular}
\end{center}

CI invokes \texttt{cargo run -{}-release -p ghc-cli -{}- demo} on
every push; a green build is the canonical operational
reproducibility certificate.

\paragraph{Services (Python).}
\path{services/ghc_api} is a FastAPI gateway. \path{services/ghc_ml}
hosts the ML pipelines: LayoutLMv3 \cite{layoutlm} for ingredient OCR,
multilingual BERT/XLM-R for label NLP, and PyTorch-Geometric GNNs for
supply-chain risk. \path{services/ghc_traceability} adapts OpenEPCIS.
These remain Phase D/E targets.

\paragraph{Spec.}
\path{spec/} publishes the GHC Protocol as Markdown plus JSON Schema +
JSON-LD contexts. The data model extends EPCIS~2.0 \cite{epcis2} and
W3C PROV-O \cite{provo}; attestations are W3C Verifiable Credentials
\cite{vc}. The \texttt{ghc-cli} \texttt{prove} / \texttt{verify}
subcommands produce/consume the binary serialization that the v0.1
spec will wrap in a VC envelope.

\paragraph{Integrations.}
\path{integrations/certifiers/} ships query-on-demand adapters for
JAKIM, MUI/BPJPH, HFA, ESMA, SFDA, and SMIIC registries (subject to
each registry's terms of service; Phase D).
\path{integrations/dlt/evm/} ships the EVM-side ZK pipeline as of
v0.0.x: a Circom \cite{circom} port of the
\texttt{HalalThresholdCircuit} compiling to BN254 (alt\_bn128), a
\texttt{snarkjs}-generated Solidity Groth16 verifier deployable to
any EVM L2, and an end-to-end assertion suite
(\texttt{scripts/test.sh}) that builds the circuit, runs a
local powers-of-tau ceremony, generates the proving and verifying
keys, proves a halal-only witness, verifies it, exports Solidity
calldata, and confirms haram verdicts are rejected at witness
generation. The Hyperledger Fabric chaincode \cite{fabric} for
consortium deployments remains a Phase D target.
