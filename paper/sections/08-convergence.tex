\section{The Compliance Convergence Theorem}
\label{sec:convergence}

A practical question for any audit-driven regime is: \emph{how many
audits are enough?} GHC answers this quantitatively under a martingale
model.

\subsection{Audit model (Phase B+)}

Let $\theta^\star \in \Lat$ be the (unknown) true compliance state of a
producer, and let $(\theta_t)_{t \geq 1}$ be the GHC posterior after $t$
audits. Each audit returns a noisy observation
$O_t = \theta^\star + \xi_t$ where $\xi_t$ is a bounded martingale
difference $|\xi_t| \leq c_t$ adapted to $\mathcal{F}_t$.

\begin{theorem}[Compliance convergence --- Phase B+ statement]
\label{thm:convergence}
Under the assumptions above,
\[
   \Pr\!\bigl[\,\|\theta_t - \theta^\star\| \geq \varepsilon\,\bigr]
   \;\leq\; 2 \exp\!\bigl( -2 \varepsilon^2 \cdot t \cdot
   \bar c^{-2} \bigr)
   \quad\text{(Azuma--Hoeffding \cite{azuma})}.
\]
Equivalently, $t = O\bigl(\bar c^2 \varepsilon^{-2}
\log \delta^{-1}\bigr)$ audits suffice to bound posterior error by
$\varepsilon$ with confidence $1 - \delta$.
\end{theorem}

The exponential-rate Azuma--Hoeffding statement requires the
sub-Gaussian MGF bound (Hoeffding's lemma) which mathlib does not yet
ship; that closure remains on the Phase~C+ roadmap. We do however
deliver two intermediate concentration inequalities now, which
together cover the operational use case:

\begin{theorem}[Audit Chebyshev concentration; mechanized]
\label{thm:audit-cheby}
For any audit random variable $X \in L^2(\Omega, \mu)$ on a finite
measure space and any precision $c > 0$,
\[
\mu\{\omega : c \leq |X(\omega) - \mathbb{E}[X]|\}
\;\leq\; \mathrm{Var}(X) / c^2.
\]
With $n$ independent audits, the empirical mean concentrates with
rate $\mathrm{Var}(X)/(n c^2)$.
\end{theorem}

\begin{theorem}[Audit Chernoff upper tail; mechanized]
\label{thm:audit-chernoff}
For any $t \geq 0$, any $\varepsilon$, and any $X$ with
$e^{tX}$ integrable,
$\mu\{\omega : \varepsilon \leq X(\omega)\}.\mathrm{toReal}
   \leq e^{-t\varepsilon} \cdot \mathrm{mgf}(X, \mu, t).$
\end{theorem}

\begin{proof}[Proof (mechanized)]
\Cref{thm:audit-cheby}: instantiate
\texttt{ProbabilityTheory.meas\_ge\_le\_va\-riance\_div\_sq};
mechanized as \texttt{Convergence.audit\_chebyshev} in
\path{proofs-mathlib/GhcMathlib/Convergence.lean}.
\Cref{thm:audit-chernoff}: instantiate
\texttt{ProbabilityTheory.measure\_ge\_le\_exp\_mul\_mgf};
mechanized as \texttt{Convergence.audit\_chernoff}.
\end{proof}

\subsection{Discrete kernel (mechanized)}

The deterministic (zero-noise) boundary of \Cref{thm:convergence} is
provable in pure Lean. We model the audit log as a list of verdicts
$\mathrm{audits} \in \Lat^*$, define a count-based plurality vote
$\mathrm{plurality}(\mathrm{audits})$ with $\haram$ as the conservative
tiebreaker, and prove that unanimity recovers the truth exactly.

\begin{theorem}[Convergence kernel; mechanized]
\label{thm:convergence-kernel}
For any audit log $\mathrm{audits}$ and target verdict $v$:
\begin{enumerate}[label=(C\arabic*)]
  \item \emph{Count bound:} $\mathrm{count}(\mathrm{audits}, v) \leq
        |\mathrm{audits}|$.
  \item \emph{Unanimity recovery:} if every audit returned $v$, then
        $\mathrm{count}(\mathrm{audits}, v) = |\mathrm{audits}|$.
  \item \emph{Zero count for non-targets:} if every audit returned $v$
        and $w \neq v$, then $\mathrm{count}(\mathrm{audits}, w) = 0$.
  \item \emph{Plurality unanimity:} if the audit log is nonempty and
        every audit returned $v$, then
        $\mathrm{plurality}(\mathrm{audits}) = v$.
\end{enumerate}
\end{theorem}

\begin{proof}[Proof (kernel)]
By induction on the audit list, with case analysis on the target
verdict for the plurality claim; mechanized in
\texttt{proofs/Ghc/Conver\-gence.lean} via
\texttt{Convergence.count\_le\_length}, \texttt{count\_unanimous},
\texttt{count\_unanimous\_other}, and \texttt{plurality\_unanimous}.
\end{proof}

\Cref{thm:convergence-kernel} is the deterministic ($\bar c \to 0$)
limit of \Cref{thm:convergence}: with no audit noise, a single audit
suffices, and any number of unanimous audits recovers the truth. The
probabilistic refinement quantifies the rate at which this holds when
$\bar c > 0$.
