# DLT Anchoring

Two reference deployments are planned:

1. **Hyperledger Fabric chaincode** (`fabric/`) — for consortium
   deployments where authorities run validating peers.
2. **EVM L2 verifier contract** (`evm/`) — for open / consumer-facing
   deployments. The Solidity verifier is generated by snarkjs from the
   Circom port of the `ghc-zk` Groth16 circuit.

Phase D delivers both. Until then this directory holds only design
notes and contract interfaces (`fabric/contracts.md`, `evm/IGhcVerifier.sol`).
